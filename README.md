# Duet Night Abyss Guide

A comprehensive character guide website for Duet Night Abyss.

**Live Site:** https://duetnightabyss.gachabuild.com
**CMS Studio:** https://studio.duetnightabyss.gachabuild.com

## Features

- Interactive tier lists (Farming, Party, Boss modes)
- 24 characters with detailed information
- 35 weapons database
- Advanced filtering (element, role, weapon)
- Responsive design
- Multi-language support (EN/VI)
- Sanity CMS integration

## Tech Stack

- Next.js 15 + TypeScript
- TailwindCSS
- Sanity CMS
- Docker

## Quick Start

```bash
npm install
cp .env.example .env.local
npm run dev
```

See `docs/` for detailed documentation.
